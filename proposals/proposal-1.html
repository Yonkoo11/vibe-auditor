How It Works

Snapshot

Records git state, detects framework, maps your codebase. Nothing changes until you say so.

Parallel Audit

3 agents scan simultaneously: Security, Auth, and Secrets. Each one specialized, running concurrently.

Auto-Fix

Surgical edits that preserve your code style. No rewrites. No reformatting. Just the fix.

Test Gen

Every fix gets a test. Regression coverage generated automatically, matched to your test framework.

Report

Terminal output for you. Shareable HTML report card for your team. Before/after diff included.

# Audit + auto-fix
