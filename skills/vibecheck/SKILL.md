# Vibe Check Skill

This skill auto-activates when the user mentions auditing, checking, or fixing vibe-coded projects.

## Activation triggers
- "check my code for security issues"
- "audit this project"
- "is this production ready"
- "find vulnerabilities"
- "hardcoded secrets"
- "missing auth"
- "vibe check"
- "make this production ready"

## When activated
Suggest running `/vibecheck` to perform a full audit, or `/vibecheck --fix` to audit and auto-fix.
